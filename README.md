# 전국 센터 출퇴근 관리 시스템

전국 12개 센터 직원의 **출근 · 외출 · 복귀 · 퇴근**을 휴대폰으로 기록합니다.

- 기록 즉시 **각 센터장에게 이메일 / 카카오 알림톡** 발송
- 회장용 **실시간 현황 시트**가 기록마다 자동 갱신 (Google 스프레드시트 = 온라인 엑셀)
- 정해진 시각마다 **회장에게 엑셀(.xlsx) 첨부 보고서** 이메일 + 알림톡 요약 발송
- 센터장에게도 같은 시각에 **자기 센터의 미출근 · 외출중 · 지각 명단** 발송

별도 서버 없이 **Google 스프레드시트 + Apps Script**로 동작합니다. 추가 비용은 알림톡 발송비뿐입니다.

```
 직원 휴대폰 (웹앱)            Google 스프레드시트                         받는 사람
 ┌──────────────┐  기록   ┌──────────────────────┐  즉시 알림       ┌──────────────┐
 │ 출근/외출/   │ ──────▶ │ [기록] 시트에 저장     │ ──────────────▶ │ 각 센터장      │
 │ 복귀/퇴근    │         │ [실시간현황] 자동 갱신 │  이메일·알림톡    │ (12명)        │
 └──────────────┘         └──────────────────────┘                 └──────────────┘
                                   │  보고 시각마다 (예: 09:30 / 13:30 / 18:30)
                                   ▼
                          엑셀 첨부 이메일 + 알림톡 요약  ─────────▶  회장
```

---

## 시트 구성

| 시트 | 내용 | 누가 관리 |
|---|---|---|
| **실시간현황** | 센터별 요약표(전체/출근/지각/근무중/외출중/퇴근/미출근) + 직원별 상세 | 자동 |
| **기록** | 모든 출퇴근 기록 (일자, 시각, 직원, 구분, 비고, 위치) | 자동 |
| **설정** | 회장 연락처, 출근 기준시각, 보고 시각, 알림 사용 여부 등 | 관리자 |
| **센터** | 12개 센터: 센터코드, 센터명, 센터장 이름·이메일·휴대폰, 위치(선택) | 관리자 |
| **직원** | 사번, 이름, 센터코드, 휴대폰, PIN, 재직여부 | 관리자 |

## 설치 (약 20분)

### 1. 스프레드시트와 스크립트 만들기
1. 회사 Google 계정으로 [새 스프레드시트](https://sheets.new)를 만듭니다. (이름 예: `근태관리`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 이 저장소의 `src/` 폴더 파일을 같은 이름으로 만들어 내용을 붙여 넣습니다.
   - `Logic.gs`, `Sheets.gs`, `Attendance.gs`, `Notify.gs`, `Report.gs`, `Setup.gs` → **스크립트** 파일 (`.gs`)
   - `Index.html` → **HTML** 파일 (이름은 `Index`)
   - `appsscript.json` → 프로젝트 설정(⚙) → "편집기에서 appsscript.json 매니페스트 파일 표시"를 켠 뒤 내용 교체
   > 개발자라면 [clasp](https://github.com/google/clasp)로 `src/` 폴더를 한 번에 올릴 수 있습니다 (`clasp create --type sheets --rootDir src` → `clasp push`).
4. 저장 후 스프레드시트를 새로고침하면 상단에 **근태관리** 메뉴가 생깁니다.

### 2. 초기 설정
1. **근태관리 → 1. 초기 설정** 실행 (처음 한 번 권한 승인 필요)
2. 생성된 시트를 채웁니다.
   - **설정**: `회장 이메일`, `회장 휴대폰`, `출근 기준시각`, `보고 시각` 등
   - **센터**: 12개 센터 행이 미리 만들어져 있습니다. 센터명과 센터장 이메일·휴대폰을 입력하세요.
   - **직원**: 사번 / 이름 / 센터코드(C01~C12) / PIN(직원별 4~6자리 숫자) 입력. 퇴사자는 `재직`을 `N`으로.
3. **근태관리 → 알림 테스트**로 회장 이메일이 오는지 확인합니다.

### 3. 직원용 출퇴근 화면 배포
1. Apps Script 편집기에서 **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**  → 배포
3. 나온 **웹 앱 URL**을 직원들에게 공유 (단톡방 공지, QR코드를 센터 입구에 부착 등)
   - 직원은 Google 계정 없이 **사번 + PIN**으로 사용합니다.
   - 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
   > 코드를 수정한 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

### 4. 자동 보고 시작
**근태관리 → 2. 자동 보고 시작**을 실행합니다.
- 5분마다 확인하여 `보고 시각`이 지나면 보고서를 발송합니다 (지정 시각 후 5분 이내).
- `근무 요일`에 해당하는 날만 발송합니다.

### 5. 회장님 실시간 열람
스프레드시트 **공유** 버튼 → 회장님 이메일을 **뷰어**로 추가합니다.
휴대폰 Google 스프레드시트 앱에서 **실시간현황** 시트를 열면 언제든 최신 현황을 볼 수 있습니다.
(언제든 **파일 → 다운로드 → Microsoft Excel**로 받을 수도 있습니다.)

## 카카오 알림톡 설정 (선택)

알림톡은 카카오 정책상 **사업자 카카오톡 채널 + 공식 발송대행사 + 사전 승인된 템플릿**이 필요합니다.
이 시스템은 발송대행사 **[솔라피(SOLAPI)](https://solapi.com)** API를 사용합니다. (건당 약 8~13원, 실패하면 문자로 자동 대체 발송)

1. [카카오톡 채널](https://center-pf.kakao.com) 개설 → **비즈니스 채널** 인증
2. 솔라피 가입 → 발신번호 등록 → 카카오 채널 연동 → **pfId** 확인
3. 솔라피에서 아래 **템플릿 2개**를 등록하고 검수 승인을 받습니다 (보통 1~3 영업일).

**① 출퇴근 알림 템플릿 (이벤트)**
```
[#{센터}] 근태 알림
#{이름}님이 #{구분} 처리되었습니다.
시각: #{시각}
비고: #{비고}
```

**② 현황 보고 템플릿 (보고)**
```
[근태 보고] #{일자} #{시각}
#{범위} 현황
전체 #{전체}명 / 출근 #{출근}명
지각 #{지각}명 / 미출근 #{미출근}명
외출중 #{외출}명 / 퇴근 #{퇴근}명
```

4. 승인된 **템플릿 ID**, **pfId**, **발신번호**를 [설정] 시트에 입력하고 `알림톡 알림`을 `Y`로 변경
5. **근태관리 → 알림톡 API 키 등록** 메뉴에서 솔라피 API Key / Secret 입력
   (키는 시트가 아닌 스크립트 속성에 보관되어 시트를 공유해도 노출되지 않습니다)
6. **알림 테스트**로 회장 휴대폰에 알림톡이 오는지 확인

> 템플릿 문구를 바꾸면 변수명(`#{센터}` 등)은 그대로 두어야 합니다. 변수를 바꾸려면 `Notify.gs` / `Report.gs`의 `variables`도 함께 수정하세요.

## 주요 설정 항목 ([설정] 시트)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 출근 기준시각 / 지각 허용(분) | 09:00 / 10 | 09:10 이후 출근은 **지각** |
| 퇴근 기준시각 | 18:00 | 이전 퇴근은 **조퇴**로 표시 |
| 보고 시각 | 09:30, 13:30, 18:30 | 아침=출근 현황, 낮=외출 현황, 저녁=퇴근 현황. 자유롭게 추가 |
| 이메일 알림 / 알림톡 알림 | Y / N | 센터장 실시간 알림 방식 |
| 회장 실시간 알림 | N | Y면 모든 출퇴근 건을 회장에게도 즉시 발송 (12개 센터면 하루 수백 건이므로 권장하지 않음) |
| 센터장 정기보고 | Y | 보고 시각마다 센터장에게 자기 센터 현황 발송 |
| 위치 확인 | N | Y면 휴대폰 GPS로 센터 반경 안인지 확인. [센터] 시트에 위도·경도 입력 필요 (구글 지도에서 우클릭 → 좌표 복사). 반경 밖이어도 기록은 되며 "범위밖"이 표시되고 알림에 포함됩니다. |

## 동작 규칙
- 상태 흐름: `미출근 → 출근 → (외출 ↔ 복귀) → 퇴근`. 순서에 맞지 않는 버튼은 비활성화되며 서버에서도 거부합니다.
- 외출 중에 바로 퇴근할 수 있습니다.
- 퇴근 후 다시 출근 처리는 불가합니다. 잘못 누른 경우 관리자가 [기록] 시트에서 해당 행을 삭제하면 됩니다.

## 사용량 한도 (Google 무료/Workspace 계정)
- 이메일 발송: 일반 Gmail 하루 100명, **Google Workspace 하루 1,500명**.
  직원 수 × 4회 이벤트 알림을 보내야 하므로, 직원이 25명보다 많으면 **Workspace 계정 사용** 또는 **이메일 대신 알림톡 사용**을 권장합니다.
- [기록] 시트는 1년에 약 (직원 수 × 1,000)행씩 늘어납니다. 해가 바뀌면 [기록] 시트를 복사해 보관하고 내용을 비우면 됩니다.
